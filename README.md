# 오늘 뭐먹지? · 서울대 식단 노트

식샤의 공개 식단으로 한 끼를 고르고, 실제 먹은 메뉴와 칼로리를 기기에 기록하는 웹앱입니다.

게시 주소: https://joemg1011.github.io/mysnu-meal-recommender/

## 실행과 검사

Node.js 24 이상에서 실행합니다.

```text
npm ci
npm run dev
npm test
npm run typecheck
npm run build
```

개발 주소는 http://localhost:3000 입니다. GitHub의 `main`에 변경을 올리면 기존 배포 과정이 테스트 → 타입 검사 → 정적 빌드를 통과한 뒤 같은 GitHub Pages 주소에 게시합니다.

## 식단 조회와 기록

- 날짜, 식당, 끼니를 선택하고 메뉴명 또는 식당명으로 검색합니다. 추천도 현재 식당·끼니·검색 범위 안에서 고릅니다. 메뉴명에 드러난 제외 재료와 기기에 저장한 관심 표시를 함께 고려합니다.
- 실제 먹은 메뉴에 **먹었어요**를 누르면 선택한 날짜에 저장됩니다. 미래 날짜에는 기록할 수 없습니다.
- **추정 근거·분량 보기**에서 계산 가정과 출처를 확인합니다. **칼로리·분량 수정**으로 실제 양이나 영양표시를 반영할 수 있습니다.
- **식단 등록**에서 날짜·식당·끼니와 메뉴를 직접 추가할 수 있습니다. 사진 OCR은 Tesseract.js로 기기에서 실행하며, 처음에는 한글·영어 언어 파일을 내려받습니다. 인식 결과는 직접 확인하고 수정해야 합니다. 사진은 이 앱의 서버에 업로드하지 않습니다.
- **AI 상담**은 메뉴·추정 근거를 질문으로 만들어 복사하는 도구입니다. ChatGPT를 직접 열고 붙여넣어 사용합니다. 자동 전송이나 내장 AI 대화는 제공하지 않습니다.

## 연결 실패 처리

12초 안에 응답이 없으면 요청을 중단하고 같은 날짜의 마지막 저장 식단을 표시합니다. 조회 결과는 최근 갱신 7건을 보관합니다. 캐시에는 식샤의 공개 응답만 저장하며, 개인 기록과 구분합니다. 저장된 자료인지와 마지막 확인 시각을 표시하고, 수동 새로고침·연결 복구 시 재요청·10분 자동 갱신을 지원합니다.

저장된 해당 날짜 식단도 없으면 오류 상태와 직접 등록 동선을 보여 줍니다. 실제 데이터 대신 예시 메뉴를 자동으로 넣지 않습니다. 이전 버전에 저장된 예시 섭취 기록은 ‘이전 예시 메뉴’로 보존하면서 합계에서 제외합니다.

## 칼로리의 의미

해당 식당에서 실측한 값이 아닌 참고 추정치입니다. 기존 기록의 칼로리는 자동으로 덮어쓰지 않습니다.

1. 식약처 K-FIND 음식 DB의 기준량당 열량을 참고 제공량으로 환산합니다. `lib/mfds-foods.ts`는 2026-08-28 배포본에서 프랜차이즈 수치 등을 제외한 2,154개 음식 자료입니다. 원본 가공 과정은 `scripts/extract-mfds.ps1`, `scripts/build-mfds-reference.mjs`에 있습니다.
2. 정확한 항목이 없으면 유사 음식 또는 재료별 중량·열량밀도로 추정합니다. 국수는 익힌 면을, 정식은 주요리·밥·국·반찬을 함께 계산하고 가정을 표시합니다. 버거 세트는 감자튀김·음료를 가정하며 밥을 추가하지 않습니다. ‘밥 별도’는 밥을 제외합니다.
3. S/L/R처럼 실제 중량이 없는 크기는 기준 중량의 0.75/1.3/1배로 가정하고 낮은 신뢰도를 표시합니다. 여러 주요리가 있는 일부 조합은 각각 65% 분량을 가정합니다. 범위는 통계적 신뢰구간이 아닙니다.
4. 식샤에 실제 중량·조리법·영양표시가 없어서 학식 실측치와의 오차율은 검증되지 않았습니다. 실제 양을 알면 메뉴별로 수정해 주세요.

식품 자료: https://various.foodsafetykorea.go.kr/nutrient/general/down/list.do

알레르기·제외 재료는 메뉴명에서만 판단합니다. 실제 포함 성분은 식당에 확인해야 합니다.

## 기기 저장과 구조

계정 로그인 없이 이 브라우저의 `localStorage`에 관심 표시, 날짜별 섭취 기록, 목표 칼로리, 선호와 제외 재료, 직접 등록 식단과 수정값을 저장합니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다.

- `lib/calories.ts`: 음식별 계산과 분량 가정
- `lib/siksha.ts`: 식샤 응답 검증·취소 가능한 요청·날짜별 공개 식단 캐시
- `lib/meal-storage.ts`: 손상된 저장값 검사, 이전 예시 기록 구분, 합계 계산
- `app/page.tsx`: 날짜·검색·추천·기록·OCR 화면
- `tests/`: 계산 오류, 날짜 불일치, 요청 취소, 캐시, 저장 기록 회귀 검사

수정 내역은 [개선점 목록](docs/IMPROVEMENTS.md)에 정리했습니다.
